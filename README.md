# 📺 Vidio EPG Checker

Aplikasi berbasis Streamlit untuk memverifikasi, mengecek, dan menyinkronkan kesesuaian jadwal EPG siaran live (Sports & Non-Sports) di platform Vidio.

## 🛠️ Fitur Utama
- **Automated EPG Verification**: Pengecekan jadwal siaran otomatis berdasarkan tanggal.
- **Custom Channel Mapping**: Penambahan channel kustom dan Live Stream ID secara manual/UI.
- **Google Sheets Integration**: Sinkronisasi data jadwal langsung dari Google Sheets.
- **Multi-Category Checker**: Dukungan pengecekan kategori Sports & Non-Sports.
